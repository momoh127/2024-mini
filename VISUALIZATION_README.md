# CyberTipline Reports Visualization

Professional visualization suite for presenting CyberTipline Reports data (2021-2023) to teachers, investors, and stakeholders.

## 📊 Generated Visualizations

The script generates **3 high-resolution presentation-ready charts**:

### 1. **cybertipline_reports_visualization.png** (Comprehensive 6-Panel Analysis)
A detailed dashboard containing:
- **Total Reports Trend**: Bar chart showing overall growth
- **Stacked Breakdown**: Public vs ESP reports composition
- **Side-by-Side Comparison**: All report types grouped by year
- **Growth Rate Analysis**: Year-over-year percentage changes
- **Public Reports Detail**: Focused view on public submissions
- **ESP Reports Detail**: Focused view on ESP (Electronic Service Provider) submissions
- **Key Insights Box**: Statistical summary and findings

### 2. **cybertipline_trend_chart.png** (Line Chart Trends)
A clean trend analysis showing:
- Three-year progression for all report categories
- Annotated data points with exact values
- Clear visual distinction between report types
- Professional styling perfect for presentations

### 3. **cybertipline_distribution.png** (Distribution & Summary)
A comprehensive overview featuring:
- 2023 pie chart showing Public vs ESP distribution
- Detailed year-by-year breakdown with absolute numbers
- Growth percentages for each category
- Executive summary format

## 🚀 Quick Start

### Installation

```bash
# Install required dependencies
pip install -r requirements.txt
```

### Run the Script

```bash
python3 cybertipline_visualization.py
```

### Output

Three PNG files will be generated in the current directory at 300 DPI resolution, suitable for:
- PowerPoint/Keynote presentations
- Printed materials
- Reports and documentation
- Web publishing
